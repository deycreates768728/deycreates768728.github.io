## Built with

Plain HTML/CSS — no build step or framework required. Hosted for free on GitHub Pages.

## Editing

Open `index.html` in any text editor:
- Text content sits directly inside each section's HTML tags
- Colors/fonts are controlled by CSS variables near the top of the `<style>` block (`--ink`, `--teal`, `--amber`, `--paper`)
- Each project is a repeatable `<div class="project">...</div>` block — copy, edit, or delete as needed

After editing, re-upload the changed file(s) to this repo to publish the update (GitHub Pages redeploys automatically).
